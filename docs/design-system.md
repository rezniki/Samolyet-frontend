# Samolyet — Design System и UI Inventory

Документ составлен по текущему коду в `src` (включая экраны приложения и базовые UI-компоненты).

## 1) Дизайн-система

### 1.1 Цвета (hex)

Ниже перечислены все найденные hex-цвета в проекте `src`:

- `#2563EB` — основной синий (primary, CTA-кнопки, активная навигация, бейджи)
- `#1E40AF` — hover для primary
- `#EC4899` — акцент/лайк/розовые элементы
- `#FBCFE8` — светлый акцентный фон
- `#F8FAFC` — основной светлый фон
- `#1E293B` — основной текст
- `#64748B` — вторичный текст
- `#E2E8F0` — границы и нейтральные состояния
- `#FFFFFF` — белый (карточки, текст на primary)
- `#EF4444` — destructive/error/logout
- `#10B981` — success (token в теме)
- `#F59E0B` — warning (token в теме)
- `#60A5FA` — иконка пустого состояния чатов / старый вариант в закомментированном коде
- `#3B82F6` — цвет цели friendship (экран выбора цели)
- `#CBD5E1` — disabled-состояние кнопки Continue
- `#94A3B8` — вспомогательный текст/подсказка
- `#030213` — sidebar primary token
- `#ccc` — служебные stroke-селекторы в `ui/chart`
- `#fff` — служебные stroke-селекторы в `ui/chart`

### 1.2 Размеры шрифтов

Базовые размеры:

- `html` / `1rem = 16px` (`--font-size: 16px`)
- Заголовки в теме:
  - `h1: 32px` (`2rem`)
  - `h2: 24px` (`1.5rem`)
  - `h3: 20px` (`1.25rem`)
- На экранах и в UI встречаются:
  - `text-xs` (`12px` / `0.75rem`)
  - `text-sm` (`14px` / `0.875rem`)
  - `text-base` (`16px` / `1rem`)
  - inline: `13px`, `16px`, `24px`

### 1.3 Отступы между элементами

Чаще всего используются шаги Tailwind-сетки (при базе `1 = 4px`):

- `0.5` = `2px` (например, `mt-0.5`)
- `1` = `4px`
- `1.5` = `6px`
- `2` = `8px`
- `3` = `12px`
- `4` = `16px`
- `6` = `24px`
- `8` = `32px`
- `20` = `80px` (нижний отступ контента под fixed-nav: `pb-20`)

Типовые паттерны:

- Контейнеры экранов: `p-4`/`p-6`/`p-8`
- Вертикальные ряды: `space-y-3`, `space-y-4`, `space-y-8`
- Ряды элементов: `gap-1`, `gap-2`, `gap-3`, `gap-4`
- Плашки/чипы: `px-3 py-1.5`, `px-4 py-2`

### 1.4 Радиусы скругления

Используемые радиусы:

- Глобальный токен: `--radius: 1rem` (`16px`)
- Производные токены:
  - `--radius-sm: 12px`
  - `--radius-md: 14px`
  - `--radius-lg: 16px`
  - `--radius-xl: 20px`
- На экранах:
  - `rounded-full` (круглые аватары/бейджи/индикаторы)
  - `rounded-3xl` (`24px`)
  - `rounded-2xl` (`16px`)
  - `rounded-xl` (`12px`)
  - inline `borderRadius: '12px'`, `borderRadius: '26px'`
- В базовых UI-компонентах также применяются `rounded-md` и `rounded-sm`.

### 1.5 Тени

Основная тень в пользовательских экранах:

- `0 2px 8px rgba(0,0,0,0.08)` — карточки, кнопки, иконка/логотип, секции профиля
- `0 -2px 8px rgba(0,0,0,0.08)` — нижняя навигация
- `0 4px 12px rgba(0,0,0,0.1)` — выбранная цель на `GoalSelectionScreen` (inline style)

В библиотечных `ui/*` дополнительно используются стандартные токены Tailwind: `shadow-sm`, `shadow-md`, `shadow-lg`, `shadow-xl`, `shadow-xs`.

## 2) Экраны

В приложении реализованы 5 экранов/состояний:

1. `WelcomeScreen`
2. `GoalSelectionScreen`
3. `HomeScreen` (вкладка main)
4. `ChatsScreen` (вкладка main)
5. `ProfileScreen` (вкладка main)

Плюс общий контейнер `App` с bottom-nav и переключением экранов.

### 2.1 `WelcomeScreen`

**Компоненты на экране**

- Лого-блок (`AirplaneHeartIcon`) в синем контейнере
- Заголовок + подзаголовок
- Список фич (иконки `Heart`, `Sparkles`, `Users`)
- Кнопки: `Начать`, `Я уже имею аккаунт`
- Footer-текст с условиями

**Статические данные**

- Название: `Samolyet`
- Описание: `Найди тех людей, которые хотят того же, что и ты`
- 3 буллета фич:
  - `Аутентичные связи, основанные на общих намерениях`
  - `Никаких бесконечных свайпов, только значимые совпадения`
  - `Будьте прозрачны в том, что вы ищете`

### 2.2 `GoalSelectionScreen`

**Компоненты на экране**

- Заголовок и описание
- Список карточек целей (кликабельные карточки с иконкой и описанием)
- Кнопка `Продолжить` (disabled до выбора)
- Подсказка внизу

**Статические данные**

- Цели (3 шт):
  - `serious`: `Серьезные отношения`
  - `friendship`: `Дружба`
  - `casual`: `Случайные знакомства`
- Описания целей (строки в массиве `goals`)
- Подсказка: `Вы можете изменить цель раз в две недели в настройках`

### 2.3 `HomeScreen`

**Компоненты на экране**

- Header (`Рекомендации`)
- Индикатор прогресса профилей
- Карточка профиля:
  - фото
  - бейдж цели
  - имя/возраст
  - локация
  - bio
  - интересы (чипы)
  - плашка `matchReason`
  - кнопки действия (`Heart` и `Написать`)

**Статические данные**

- `mockProfiles` из 3 профилей:
  - Александра, 26 (Москва)
  - Дмитрий, 29 (Санкт-Петербург)
  - Мария, 24 (Москва)
- Для каждого: `photo`, `bio`, `interests`, `goal`, `matchReason`

### 2.4 `ChatsScreen`

**Компоненты на экране**

- Header (`Чаты`)
- Empty state (иконка `MessageCircle`, заголовок, текст)
- CTA-кнопка `Просмотр рекомендаций`

**Статические данные**

- `hasChats = false` (жестко задано)
- Тексты пустого состояния:
  - `Нет сообщений, пока`
  - `Начните разговор с теми, кто вам нравится`

### 2.5 `ProfileScreen`

**Компоненты на экране**

- Header (`Профиль`)
- Карточка профиля:
  - аватар + overlay-иконка редактирования
  - имя/возраст
  - локация
  - бейдж текущей цели
- Секции:
  - `Обо мне`
  - `Интересы` (чипы)
- Кнопка `Редактировать профиль`
- Список настроек (кнопки-строки)

**Статические данные**

- Имя: `Ваше Имя, 27`
- Локация: `Москва, Россия`
- Текст `Обо мне` (2 предложения)
- Интересы: `Фотография`, `Путешествия`, `Спорт`, `Музыка`
- Пункты настроек:
  - `Изменить цель`
  - `Уведомления`
  - `Приватность & Безопасность`
  - `Помощь & Поддержка`
  - `Выйти из аккаунта`

### 2.6 Навигация между экранами

- До main: `welcome -> goal-selection -> main`
- В main переключение вкладок через `BottomNavigation`:
  - `home` (`Рекомендации`)
  - `chats` (`Чаты`)
  - `profile` (`Профиль`)

## 3) Компоненты

### 3.1 Кнопки

Базовый компонент: `src/app/components/ui/button.tsx`.

**Варианты (`variant`)**

- `default` — фактически primary (`bg-primary`, белый текст)
- `secondary` — вторичная заливка (`bg-secondary`)
- Также есть: `outline`, `destructive`, `ghost`, `link`

**Размеры (`size`)**

- `default`, `sm`, `lg`, `icon`

**Как используется в экранах**

- Primary: `Начать`, `Написать`, `Просмотр рекомендаций`, `Редактировать профиль`
- Secondary/neutral (через outline): `Я уже имею аккаунт`
- Специальное состояние disabled: `Продолжить` на `GoalSelectionScreen` (inline button, не `ui/button`)

### 3.2 Инпуты и формы

- `Input`: `src/app/components/ui/input.tsx`
  - `h-9`, `rounded-md`, `border`, `px-3 py-1`, `text-base/md:text-sm`
  - focus-ring: `focus-visible:ring-[3px]`
- Форменная обвязка: `src/app/components/ui/form.tsx` (интеграция с `react-hook-form`)
- Дополнительно присутствуют:
  - `Textarea`
  - `Select`
  - `InputOTP`
  - `RadioGroup`
  - `Switch`

Примечание: в текущем пользовательском флоу (5 экранов) полноценные формы с вводом данных почти не задействованы; экраны в основном контентно-навигационные.

### 3.3 Карточки профилей

Карточки реализованы вручную в `HomeScreen` и `ProfileScreen` (а не через `ui/card`):

- Белый фон (`bg-white`)
- Радиус `rounded-2xl`
- Тень `0 2px 8px rgba(0,0,0,0.08)`
- Внутренние отступы `p-6` / `p-4`
- Состав:
  - медиа/аватар
  - имя и метаданные (возраст, локация)
  - контент (`bio`, `interests`)
  - action area (кнопки или ссылки-настройки)

### 3.4 Навигация

`BottomNavigation`:

- Fixed снизу (`fixed bottom-0 left-0 right-0`)
- Высота панели `h-16` (`64px`)
- 3 таба: рекомендации / чаты / профиль
- Состояния:
  - active: `text-[#2563EB]` + `font-semibold` для подписи
  - inactive: `text-[#64748B]` + hover `text-[#1E293B]`
- Верхняя граница `border-[#E2E8F0]` и тень `0 -2px 8px rgba(0,0,0,0.08)`
